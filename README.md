# 极速飞车 3D 🏎️

QQ飞车风格卡丁车竞速游戏。漂移集氮、氮气喷射、空喷、落地喷一应俱全，
三大主题赛道（**沙漠灰 / 新年广场 / 天空之城**，CF 风格），支持**个人挑战赛**（你 + 4 台电脑）
与**联机匹配**（≥2 人开局），完赛有 **3D 领奖台**（奖杯 + 彩带 + 掌声喝彩）。

基于 **Three.js**（r149，本地 `lib/` 内置）+ **Node WebSocket**（`ws`），
纯前端零构建，浏览器直接跑。

## 快速开始

```bash
npm install
npm start            # 默认 http://localhost:8252/
```

- **个人挑战赛**：主菜单 → 个人挑战赛 → 选主题即可，无需服务器也能玩
  （直接双击 `index.html` 或任意静态托管均可，联机功能除外）。
- **联机匹配**：同一局域网的朋友浏览器打开 `http://<本机IP>:8252/`，
  进入联机大厅；**≥2 名玩家**时房主出现"开始比赛"按钮，点击即开局。
  开局后加入的人自动转为观战。

端口/白名单可用环境变量覆盖：`PORT=9000 ALLOWED_ORIGINS=https://xxx npm start`

## 操作

| 按键 | 功能 |
| --- | --- |
| ↑ / W | 油门 |
| ↓ / S | 刹车 / 倒车 |
| ← → / A D | 转向 |
| **Shift**（按住 + 方向） | **漂移**：甩尾过弯，持续**集氮**，松开有小喷奖励 |
| **Space / Ctrl / E** | **氮气喷射**（集满 1 罐才能用，最多存 2 罐） |
| Space（**滞空时**） | **空喷**：空中免费前冲，每次滞空限一次 |
| 飞坡落地 | **落地喷**：滞空足够长自动触发 |
| R | 复位到赛道 |

提示：左上角是**全景小地图**（白箭头是你）；弯前松油、弯中 Shift+方向漂移攒氮、
出弯喷氮是最快跑法；天空之城掉下浮岛会回到检查点并冻结 1 秒。

## 主题赛道

| 主题 | 特色 |
| --- | --- |
| 🏜️ 沙漠灰 | CF 风格灰褐砂岩：古城建筑群、石拱门、木箱堆与远景金字塔 |
| 🏮 新年广场 | CF 新年广场风格：雪地雪松、红灯笼灯柱、新春横幅门与礼盒 |

## 结算

完赛自动切到 **3D 领奖台**：前三名登金银铜台阶、冠军头顶旋转金杯、
彩带纷飞 + 掌声喝彩，右侧列出全部玩家的总用时与最快单圈。

## 架构

```
index.html          入口（无内联脚本，CSP: script-src 'self'）
css/style.css       全部界面
js/
  config.js         全局参数（物理手感 / 氮气 / 联机频率）
  protocol.js       联机消息白名单校验（浏览器 / Node 共用）
  track.js          赛道生成：样条闭环 + 弧长采样 + 坡道/断崖 + 检查点
  car.js            Q版卡丁车模型 + 赛道空间街机物理（漂移/氮气/空喷/落地喷）
  scene.js          三主题环境（天空穹顶 / 装饰合批 / 赛道网格 / 起点拱门）
  effects.js        粒子特效（胎烟 / 尾焰 / 火花）+ 领奖台彩带
  audio.js          WebAudio 合成音效（引擎 / 啸叫 / 喷射 / 掌声，无音频文件）
  hud.js            HUD：左上角全景小地图 / 速度表 / 氮气条 / 排名 / 提示
  ai.js             电脑车手：走线 / 曲率限速 / 漂移 / 橡皮筋
  podium.js         3D 领奖台
  net.js            联机客户端（断线重连 / 服务器时钟对齐）
  game.js           比赛编排（倒计时 / 镜头 / 碰撞 / 远端车插值 / 结算）
  main.js           菜单 / 联机大厅 / 结算接线
server.js           HTTP 静态 + WebSocket 房间（匹配 / 中继 / 结算裁决）
lib/three.min.js    Three.js r149
```

联机模型：**每个客户端是自己车辆的权威模拟端**，12Hz 上报赛道空间状态
（里程/横偏/速度/航向…），服务器做 schema 校验、限流、中继与**结算裁决**
（按完赛用时排名，未完赛按进度垫底；比赛中掉线成绩仍保留）。

## 安全（沿用同系列台球项目的防护框架）

- HTTP：CSP（`script-src 'self'`）/ nosniff / frame-ancestors；非法编码 400；目录穿越防护
- WebSocket：maxPayload 限幅、Origin 白名单、单 IP 连接数与观战上限、
  令牌桶限速、非法消息累计断开、ping/pong 心跳、广播背压保护
- 消息：服务端不信任任何客户端字段，全部经 `protocol.js` 白名单校验

## 部署

- 静态托管（Netlify 等）可玩离线个人挑战赛：`netlify.toml` 已配好
- 联机需 Node 服务器（任何能跑 `node server.js` 的平台），前端通过
  `?ws=wss://你的服务器` 或 `window.RACER_WS_URL` 指向后端
